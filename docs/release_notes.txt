# Ollama AI Chat — Release Notes

## v1.2 — Web Chat Sync + On-Device Improvements

### What's New

**Web Chat — Chat from Any Browser**
- Access all your conversations from any desktop or laptop at chat.ollama-android.app (or directly at chartmann1590.github.io/ollama-android-client/chat.html)
- Sign in with the same Google or email account you use on the app
- Send messages from your browser — your phone picks them up, runs AI inference, and streams the response back in real time
- Works with both remote Ollama servers AND on-device LiteRT models
- Offline queue: type messages when your phone is offline; they dispatch automatically when the phone reconnects
- Real-time model selector shows only models actually installed on your phone
- Phone presence indicator shows when your phone is online and ready

**Firebase Sync**
- Enable Web Sync in Settings to start syncing threads and messages to Firebase Realtime Database
- All existing chat threads and future conversations sync automatically in the background
- Sync status shown directly in the Settings screen

**On-Device Inference Improvements**
- Fixed crash with Gemma 4 models when conversation history contained empty turns
- Improved conversation history sanitization for GPU inference stability

### Previous: v1.1 — LiteRT-LM On-Device AI

- Download and run Gemma 4, Gemma 3, Qwen 3, DeepSeek R1 Distill, and Phi-4 Mini fully on-device
- No Ollama server required for on-device inference
- Google LiteRT-LM runtime with CPU backend
- Downloads resume after network drops with free-space pre-check
- Optional Hugging Face token for gated model repos

### Previous: v1.0.0 — Initial Release

- Chat interface with multiple AI models via Ollama
- Multiple server support
- Real-time streaming responses
- Image attachment support with automatic compression
- Persistent chat history (Room database)
- Model management (list, pull, delete)
- Labels, pin, archive for thread organization
- Per-thread model parameters (temperature, top_p, top_k, num_ctx, seed)
- Token-speed stats under each reply
- Voice input (Android speech-to-text)
- Read-aloud replies (Text-to-Speech)
- Export/share chats as Markdown
- Global and in-thread message search
- Dark theme + Material Design 3
